# us_state_texas_lbb — Texas Legislative Budget Board Contracts Database (contracts.lbb.texas.gov) + CMS public detail pages

Reference date 2026-10-25. Output: `/home/claude/contracts/normalized/us_state_texas_lbb.jsonl` (**62 records**: 51 `ongoing`, 11 `end_date_unknown`). Scripts in `scripts/us_state_texas_lbb/`: `fetch_details.py` (detail-page parser), `fetch_by_vendor.py` (pass 1 probe one page per vendor ID + pass 2), `probe_parallel.py` and `fetch_pass2.py` (added on resume), `normalize.py`.

## What was downloaded
- Active-contracts export of the LBB Contracts Database (Plotly Dash app at https://contracts.lbb.texas.gov/, "Download" of the full ACTIVE list; state agencies and universities must report contracts ≥ USD 50,000) → `downloads/us_state_texas_lbb/lbb_download_contracts_active.csv`, retrieved 2026-10-25T17:42:28Z (20.97 MB, **50,878 rows**, all Status = Active). Columns: Agency, Award Date, Vendor, Contract, Contract-ID (HTML link to the CMS page), Subject, Current Contract Value, Status, Completion Date, Procurement Method, Category, NGIP Codes and Categories, Vendor ID. **No vendor address in the export.**
- Vendor addresses come from the public CMS detail page of each contract, https://cms.lbb.texas.gov/Default.aspx?aid=<agency>&cid=<contract> (redirects to `Public/SearchedList.aspx?Search=Y&aid=…&cid=…`), whose "Vendor:" table has Vendor ID, Vendor Name, Address Line 1–4, City, **State**, Postal Code, Phone, plus a summary line (award/completion date, current and max value, competitively procured?) and NIGP codes.
  - Pass 1 (one probe page per vendor ID): all 205 vendor IDs whose Texas TIN prefix is Comptroller-assigned (3, 5, 9, 6, 8, 4, 2, U, 0 — the IDs used for foreign vendors), 2026-10-25 18:14–19:01 UTC, plus — added on resume — the 6,145 `ue-…` "unverified entity" IDs used by universities/colleges, probed in parallel (5 threads, global limit ≤ 2 req/s, `probe_parallel.py`) from 19:25 UTC onward, ordered so that names with company-form tokens (LTD, LIMITED, CANADA, LTEE, ULC, INC., CORP…) go first. Two further targeted probe runs were added on resume: (a) 19:56–20:24 UTC, the 399 FEIN/SSN-based IDs (prefix 1/7) whose vendor name contains CANADA/CANADIAN/LTD/LIMITED/LTEE/ULC (353 fetched); (b) from 20:27 UTC, all 77 IDs of the form `198…` — Texas ID = "1" + FEIN, and FEINs beginning **98** are the IRS range for foreign entities — a structured-identifier criterion. In every case the country is decided only from the detail-page address (e.g. D2L Ltd probes show Baltimore MD / Towson MD / Palatine IL addresses and are therefore NOT Canadian). Results in `details/vendor_probe.jsonl` (see counts below).
  - Pass 2: every active contract of each vendor whose address is Canadian → `details/details_canadian.jsonl` + saved HTML in `details/html/`.
- The CMS server frequently resets connections (`Errno 104`); failed probes are retried 4× and otherwise left for a later run (logged in `details/*.log`).

## Canadian vendor
`is_canadian_block()`: detail-page State is a Canadian province code, OR State is `--`/blank and the address lines/City contain "CANADA" or a province + Canadian postal code. In practice the CMS stores foreign addresses with State `--` and "CANADA" in City (e.g. WESCAM INC: "50 LEAVITT BOULEVARD | WATERDOWN ON L9H 0C5 | CANADA | -- "). `vendor.country_basis` quotes the address used. Names are never used.

## Ongoing
All export rows are Status = Active. `ongoing` when Completion Date ≥ 2026-10-25 and Award Date ≤ 2026-10-25 (10); `end_date_unknown` when Completion Date is "-" (8; LBB still lists them as Active). Contracts with a completion date before the reference date or an award date after it are excluded (none among Canadian vendors).

## Known gaps
- Vendors with a US FEIN-based Texas ID (prefix 1, ≈40,000 rows) or SSN-based IDs (prefix 7) were not probed (a US-registered subsidiary would normally have a US address anyway).
- The `ue-` probe could not finish in the time budget because of the server's connection resets (≈13–29 pages/min); see the final probe count in this note's last section. Unprobed `ue-` vendors may include further Canadian vendors.
- Related Texas sources: DIR cooperative contracts → `us_state_texas_dir`; TCEQ "Current Contracts & Purchase Orders" (data.texas.gov svjm-sdfz) has vendor name only (no address) and was not used; TxDOT "Vendor List" (dw25-6md2) has no Canadian-address vendors.
