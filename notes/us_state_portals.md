# US State Portals

- Built scraper for NY OpenBook datasets from data.ny.gov using Socrata API
- Datasets included:
  - Procurement Report for State Authorities: ehig-g5x3
  - Procurement Report for Local Authorities: 8w5p-k45m
  - Procurement Report for Local Development Corporations: d84c-dk28
  - Procurement Report for Industrial Development Agencies: p3p6-xqr5
- CA filter based on vendor country, state, zip. CA is no longer used for state, and US/USA is filtered out for country
- Total records retrieved matching criteria: 715
