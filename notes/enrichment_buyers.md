## Matching rules
- GC federal: `owner_org` code from the dataset → registry (exact). CanadaBuys entity names (no owner_org) → alias regexes on the first entity of the name (`alias.py` GC_ALIAS; e.g. "Department of Public Works and Government Services (PSPC)" → pwgsc-tpsgc). Multi-entity names ("A / B / C") are joined to the first entity with `match_confidence: weak` and the full list in the basis.
- Quebec municipalities: strip designation prefix (Ville/Municipalité/Paroisse/Canton/Village, MRC/Municipalité régionale de comté) and articles, normalise accents/case/punctuation, compare with MAMH `munnom`; designation used to break homonyms (exact if designation equal, strong if the single homonym has a different designation, unresolved homonyms left unmatched with a note). Segment before " - " or " / " is used (e.g. "Ville de Montréal - Service de l'eau" → Montréal 66023).
- Health establishments: CISSS/CIUSSS/Santé Québec region core compared with Santé Québec establishment list (strong). School service centres: CSS name core equality (exact).
- Quebec agencies/crowns/universities, transit, US agencies: explicit alias table (`alias.py`) with the organisation's official domain; every such website was then fetched by the crawler (status in `extras.website_check`).
- Precision check: 30 random directory matches inspected by hand (see "Precision check" below).

## E-mail rules (precision over recall)
- Only addresses copied from the organisation's own pages/documents (or the contract dataset's own contact field for procurement role boxes), each with page URL + retrieval time + snippet in `*.evidence`.
- Personal mailboxes excluded: local parts shaped like first.last / initial+surname / name+digits without any role word are dropped (counted in crawl output as `dropped_nonrole`, never stored). Role words: factur*, invoice, payable, comptes, fournisseur, approvisionnement, achat, procurement, info, reception, greffe, dg, tresorerie, finance, …
- Class: AP = local part contains invoice/payable/facturation/AP tokens (cp, ap), or a finance/fournisseur mailbox on a page about invoices; procurement = approvisionnement/achats/procurement/contrats/soumissions; general = info/reception/municipal generic. On shared hosts (canada.ca, quebec.ca) only pages under the department's own path are used.
- No address was ever constructed from a pattern; addresses split across a line in a source (e.g. Health Canada's P2P box, CSC's NHQ bid box) were NOT re-joined into an e-mail.
- Personal-data guards applied at the end: directory e-mails that look personal (some MAMH `mcourriel` values are an employee's address) are withheld (municipality-name boxes such as levis@… are kept); 2–3-letter local parts are kept only if they are known service acronyms; a final guard drops "<first name>.<dg|dga|adj>" boxes; any non-role e-mail appearing inside a stored snippet is replaced by "[personal e-mail removed]"; intermediate work files (crawl/deep/probe logs) were scrubbed of non-role addresses (`scrub.py`, 620 removed). Raw downloaded pages are kept as fetched.

## Precision checks (done by hand on 2026-10-25)
- Directory matches: 30 random matched buyers inspected (municipalities incl. Paroisse/Canton/Village homonyms, GC alias names such as "DND Petawawa", CanadaBuys acronyms, health regions, school service centres, AU agencies, EU notice websites). 30/30 point to the right organisation; 1 caveat: "RCMP External Review Committee" carries owner_org rcmp-grc from the dataset itself, so it inherits the RCMP site.
- AP mailboxes: 35 random AP e-mails (crawler + targeted) inspected: 34/35 correct supplier-invoicing / accounts-payable role boxes; the error was an accounts-receivable box (compte-client@urgences-sante.qc.ca) — the classifier now excludes receivable/client/taxation boxes, and a token-level gate was added after a concatenated personal name (garethbillings@…) slipped into a procurement field from a notice contact; both fixed before the final assembly.
- REQ/NEQ matches: 20 random exact matches + all 82 matches whose legal form is "CIE" inspected: all correct (municipal regimes match the municipality type; the CIE cases are crowns registered as companies — Hydro-Québec, STQ, SDBJ, SPAQ — and the SQI's registered other names).
- Health-region matching bug found and fixed during the run ("de la" article stripping turned "Lanaudière" into "naudiere"); re-matched 6 more establishments.
