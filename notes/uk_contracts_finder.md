## How "Canadian vendor" was determined
Contracts Finder supplier parties have **no `address.countryName`/`country` field** (0 of 555,722 supplier parties); the address is one free-text `address.streetAddress` string (e.g. `"119 Spy Court\r\nMarkham\r\nON L3R 5H6\r\nCanada."`). Decision (names never used):
1. `streetAddress` contains the word **"Canada"** as a country (43 records) — after removing UK street/building names such as "Canada Square", "Canada Water", "Canada Farm Road", "Canada Works" (these were the false positives: KPMG, BP Oil, Rimini Street, Pixel Takeaway, Hugh L.S. McConnell, Heap & Partners …), or
2. a **Canadian postal-code pattern `A1A 1A1`** plus a province name/abbreviation (15 records), or a Canadian postal code with no other country stated (5 records: Kanata K2K…, Toronto M5V…, Vancouver V5T…). UK postcodes have the shape `A1 1AA`/`AA1A 1AA`, whose inward code is digit-letter-letter, so they cannot match the Canadian digit-letter-digit inward code.
An address with a UK postcode and no Canadian province is rejected even if it mentions Canada. The basis used is recorded per record in `vendor.country_basis`. 32 of the 484 broad candidates were rejected by the strict check (all UK addresses containing "Canada Square/Water/Farm Road/Works" or a Hertfordshire multi-supplier award whose other suppliers were UK). Structured city/region/postcode are null because the source does not split them; the full string is in `vendor.address.line1` and `raw`.

## How "ongoing" was determined
`awards[].contractPeriod.startDate ≤ 2026-10-25 ≤ awards[].contractPeriod.endDate` (fallback `tender.contractPeriod`); if start missing, award date used as the anchor. Awards with `endDate < 2026-10-25` excluded (389), start after the reference date (1), tender status `cancelled` (1). All 63 kept records have explicit start and end dates (`ongoing`); no `end_date_unknown`/`ongoing_inferred` cases arose because Contracts Finder award notices carry a mandatory contract period. `status_basis` names the fields and dates.

## Record construction
- One record per **award** (`record_id = uk_contracts_finder:<awards[].id>`, e.g. `…-1`); for multi-supplier awards the record is emitted once with the Canadian supplier as `vendor` and all suppliers listed in `contract.related.all_suppliers_on_award`; `value_detail.value_note` warns that the award value covers all suppliers (e.g. NHS Supply Chain frameworks of £300 M / £700 M with 54–73 suppliers). `instrument_type` = `framework agreement [/ multi-supplier award]` when the tender flags a framework, has >1 supplier, or the title/description says "framework"; otherwise `contract`.
- `record_url` = `awards[].documents[documentType=awardNotice].url` = `https://www.contractsfinder.service.gov.uk/Notice/<guid>`; all 63 have one. Verified: https://www.contractsfinder.service.gov.uk/Notice/b0270f4b-1ab6-4b89-aa94-d813b8947a28 renders "Awarded date 27 March 2018 / Contract start date 29 March 2018 / Contract end date 28 March 2028 / Total value £250,000 / Quanser … 119 Spy Court Markham ON L3R 5H6 Canada".
- Buyer = `buyer`/`parties[role=buyer]` with Contracts Finder party id (`GB-CFS-…`, sometimes `GB-SRS-…`), address and contact. Vendor identifiers: Companies House (`GB-COH`) when present (4 of 63), always the CF party id. CPV main + additional codes. Value/currency from `awards[].value` (GBP). Full compiled release in `raw.compiled_release`.

## Cross-portal overlap with uk_find_a_tender (for de-duplication downstream)
UK above-threshold awards are published on **both** portals: the Find a Tender notice (UK4/UK7 or TED F03, usually without a contract period) and a Contracts Finder award notice (with contract dates). Matching vendor-name stem + buyer-name stem between the two outputs gives 36 CF↔FTS pairs, of which about 12 are clearly the same contract (same value and/or same dates), e.g. Aquatic Informatics / Coal Authority (£498,182, FTS 036667-2022 vs CF d2b8e8e0-…), Nanometrics / University of Southampton (£389,350), GeoComply / BBC (£625,000), Alinea International / FCDO GEMFA 2 (£500 M framework), Angstrom Engineering / Royal Holloway (£5 M), RadTag / NHS Blood and Transplant (£156,329), Colt Canada / MoD (£4 M, 2025-07-24). Records were **not** merged across sources (different `record_id`, different notice URLs, often different stated values/dates); de-duplicate on (vendor, buyer, value or dates) if a single count of contracts is needed. Where both exist, the Contracts Finder record is the one with explicit start/end dates.

## Known gaps / limits
- Country is inferred from free text because the source has no supplier-country field; a Canadian supplier whose address string omits "Canada" AND a Canadian postal code (e.g. just "Ottawa, Ontario") is **missed** (seen in the ended set: "Entrust Limited, 2500 Solandt Road Suite 100, Kanata on K2K 3G5" would be caught by the postal code, but "Jani King of Ottawa | Ottawa, Canada" needs the word). Conversely a UK-registered subsidiary that lists its Canadian HQ address (e.g. "Circle Cardiovascular Imaging UK LTD", "Emergent BioSolutions Canda Inc") is included because the published address is in Canada.
- OCP bulk is a monthly snapshot (2026-10-05); the gap to the reference date was covered by the live API for awards *published* 2026-10-05..26, but awards *amended* in that window (an earlier notice edited) are only reflected if republished as a new award release.
- OCP's known quality issues for this publisher: a release with multiple suppliers may retain only one supplier in some older notices; some date fields unrealistic. Contracts Finder only covers England/non-devolved buyers above £12k/£30k thresholds; Scotland (Public Contracts Scotland), Wales (Sell2Wales) and Northern Ireland (eSourcing NI) are separate portals not covered here.
