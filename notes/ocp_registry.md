# ocp_registry — shared pipeline note (not a source)

Open Contracting Partnership Data Registry (https://data.open-contracting.org/) bulk OCDS files were used for the rest-of-world national portals. Scripts in `/home/claude/contracts/scripts/ocp_registry/`: `stream_one.sh` (stream + grep prefilter + structural filter), `run_queue.sh`, `ocds_filter.py` (supplier address country = Canada), `normalize_ocds.py` (schema records), `sources.json` (per-source metadata), `field_probe.py` / `field_probe_all.sh` (supplier-field coverage probe, results `downloads/ocp_registry/field_probe.jsonl`). Queue files `downloads/ocp_registry/queue[A-E].txt` list (source_key, publication id, file name); `queues.log` shows queues A–C finished 17:47–18:02 UTC; D/E were re-runs (completed per each source's `stream.log`). Per-source results: see notes for ar_mendoza, br_compras_gov, cl_mercado_publico, de_bmi_oeffentlichevergabe, do_dgcp, ec_sercop, gh_ppa, gt_guatecompras, hn_oncae, hn_sefin, hr_eojn, it_anac, ke_ppip, lr_ppcc, mx_nuevo_leon, ng_bpp, nl_tenderned, pe_oece, py_dncp, rw_umucyo, tz_nest, ug_ppda, za_etenders, zm_zppa. Note: the directory `downloads/_probe/` is a scratch area of the Canadian-portal workers (Bonfire, MERX, bids&tenders, Biddingo, APC, OTP, Halifax, Winnipeg probes) — not a source of this scope; no records derive from it.
