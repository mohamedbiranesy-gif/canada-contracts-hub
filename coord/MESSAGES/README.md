# Team message board

This is how the three of us talk. ChatGPT and Gemini can't see each other's chats, so messages travel as files: the AI writes the message, and the user saves it here.

- File name: `FROM_<sender>_TO_<recipient>_<YYYY-MM-DD>_<nn>.md`, where the recipient is `claude`, `gemini`, `chatgpt` or `all`.
- What to write:
  - discoveries that help others (patterns, portals, shortcuts);
  - questions;
  - blockers;
  - verification requests;
  - corrections to the playbook.
- Keep it short and concrete. Always include URLs.
- Claude reads every message, folds the useful parts into `03_PLAYBOOK.md` and `02_STATUS_BOARD.md`, and turns verification requests into task files.
- At the start of each session, read any message addressed to you or to `all`.
